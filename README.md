# Drei FaceMesh Demo

A minimal React + @react-three/fiber + @react-three/drei app that shows the camera feed and tracks a face using MediaPipe Tasks Vision FaceLandmarker. The letter "A" is placed on both eyes and the nose.

## Run

```bash
npm install
npm run dev
```

- Allow the browser to use the camera.
- If you see a black screen, switch to a different camera or lighting.
